# ระบบบันทึกค่าอ่านมิเตอร์น้ำและไฟฟ้า (Water & Electricity Meter Reading Management System)

Web Application สำหรับบันทึกค่าอ่านมิเตอร์น้ำและไฟฟ้า มีระบบคำนวณปริมาณการใช้อัตโนมัติ ตรวจสอบความถูกต้องของข้อมูล ดูประวัติย้อนหลัง ดูสถิติและกราฟ ออกรายงาน และส่งออกเป็น CSV หรือ Excel โดยจัดเก็บข้อมูลจริงในฐานข้อมูล SQLite

| รายการ | รายละเอียด |
|---|---|
| ภาษา / Framework | C# · ASP.NET Core MVC (.NET 10 LTS) |
| ฐานข้อมูล | SQLite + Entity Framework Core 10 (Migrations) |
| Frontend | Razor Views · Bootstrap 5.3 · Bootstrap Icons · Chart.js 4 · ฟอนต์ Sarabun / Prompt |
| Excel | ClosedXML |
| URL | **http://localhost:5058** |

---

## 1. สิ่งที่ต้องติดตั้ง

1. **.NET 10 SDK** ดาวน์โหลดได้ที่ https://dotnet.microsoft.com/download หรือติดตั้งผ่านคำสั่ง
   ```powershell
   winget install Microsoft.DotNet.SDK.10
   ```
2. NuGet packages จะถูกดาวน์โหลดให้อัตโนมัติเมื่อสั่ง build หรือ run ครั้งแรก (ต้องต่ออินเทอร์เน็ต)
   - Microsoft.EntityFrameworkCore.Sqlite 10.0.15
   - Microsoft.EntityFrameworkCore.Design 10.0.15
   - ClosedXML 0.105.1
   - System.Security.Cryptography.Pkcs 10.0.15 (บังคับใช้เวอร์ชันที่แก้ช่องโหว่แล้ว)
   - ฝั่งทดสอบใช้ xUnit
3. ไลบรารีฝั่งหน้าเว็บ (Bootstrap, Bootstrap Icons, Chart.js) เก็บไว้ใน `wwwroot/lib` แล้ว จึงใช้งานแบบออฟไลน์ได้ ยกเว้นฟอนต์ Google Fonts ที่ต้องต่ออินเทอร์เน็ต (ถ้าไม่มีอินเทอร์เน็ต ระบบจะใช้ฟอนต์ของเครื่องแทน)

> **หมายเหตุสำหรับ Windows 11:** ถ้าเปิด **Smart App Control** อยู่ Windows จะบล็อกไฟล์ `.dll` ที่ build เองในเครื่อง ทำให้รันโปรแกรมไม่ได้ และจะขึ้นข้อความ *"An Application Control policy has blocked this file"* ต้องปิด Smart App Control ก่อน โดยไปที่ Windows Security → App & browser control → Smart App Control

## 5. กฎการคำนวณ (Business Logic)

อยู่ใน `Services/ReadingService.cs`

- **ปริมาณการใช้ (Consumption) = ค่าอ่านปัจจุบัน − ค่าอ่านครั้งก่อนหน้า** โดยเรียงตาม `ReadingDate` (ไม่ได้ใช้ `CreatedAt`)
- รายการแรกของแต่ละมิเตอร์จะไม่มีปริมาณการใช้ (เก็บเป็น `null`)
- ค่าอ่านต้องไม่ติดลบ และต้องไม่ลดลงเมื่อเรียงตามวันที่ (ค่าเท่ากับครั้งก่อนบันทึกได้ จะได้ปริมาณการใช้เป็น 0)
- มิเตอร์เดียวกันบันทึกซ้ำในวันเดียวกันไม่ได้ ตรวจที่ Service และมี Unique Index `(MeterId, ReadingDate)` ในฐานข้อมูลป้องกันอีกชั้น
- การเพิ่มหรือแก้ไขข้อมูลย้อนหลังจะตรวจกับรายการก่อนหน้าและรายการถัดไป ถ้าค่าใหม่สูงกว่ารายการถัดไป ระบบจะไม่ให้บันทึก
- เมื่อเพิ่ม แก้ไข หรือลบรายการ ระบบจะคำนวณปริมาณการใช้ของมิเตอร์นั้นใหม่ทั้งชุด
- ทุกการเปลี่ยนแปลงทำภายใน Database Transaction
- กฎเพิ่มเติม: วันที่อ่านต้องไม่เป็นวันในอนาคต ต้องไม่ก่อนวันที่ติดตั้งมิเตอร์ และมิเตอร์ที่ "ยกเลิกใช้งาน" บันทึกค่าอ่านใหม่ไม่ได้
- รายงานนับปริมาณการใช้เข้าเดือน/ปีตามวันที่อ่าน (ReadingDate)

ตัวอย่างข้อความแจ้งเตือน:
> ค่าอ่านสะสม 1,300 m³ สูงกว่าค่าอ่านครั้งถัดไป (1,200 m³ เมื่อวันที่ 01/03/2026) กรุณาตรวจสอบค่าอ่านหรือวันที่อีกครั้ง

## 6. ความปลอดภัย

- POST ทุกตัวต้องมี Anti-Forgery Token (ตั้งเป็น global filter `AutoValidateAntiforgeryToken`)
- เข้าถึงข้อมูลผ่าน EF Core ที่ใช้ parameterized query ทั้งหมด จึงป้องกัน SQL Injection
- ตรวจข้อมูลทั้งฝั่งหน้าเว็บ (jQuery Validation + JS) และฝั่ง server (DataAnnotations + Service) ข้อความแจ้งเตือนเป็นภาษาไทย
- การลบต้องกดยืนยันในหน้าต่างก่อนเสมอ · `returnUrl` ยอมรับเฉพาะ URL ภายในระบบ · ป้องกันการแทรกสูตร (formula injection) ในไฟล์ CSV
- มีหน้า Error และ 404 ภาษาไทย
- NuGet packages ที่ใช้ไม่มีช่องโหว่ที่ทราบ (ตรวจด้วย `dotnet list package --vulnerable --include-transitive`)

- **ระบบล็อกอินแอดมิน:** ทุกหน้าต้องล็อกอินก่อนใช้งาน (Cookie Authentication หมดอายุใน 8 ชั่วโมง) ตั้งค่าชื่อผู้ใช้และรหัสผ่านที่ `appsettings.json` หัวข้อ `Admin`
  - บัญชีเริ่มต้นสำหรับตรวจงาน: **ชื่อผู้ใช้ `admin` / รหัสผ่าน `ChangeMe@2026`** (หน้าล็อกอินแสดงให้พร้อมปุ่มกรอกอัตโนมัติ เพราะตั้ง `ShowDemoCredentials: true`)
  - **ก่อนใช้งานจริง:** ตั้ง `ShowDemoCredentials` เป็น `false` และเปลี่ยนรหัสผ่าน (แก้ไฟล์บนโฮสต์ หรือใช้ Environment variable `Admin__Password`) พร้อมใช้ HTTPS เพราะรหัสผ่านจะวิ่งผ่านเครือข่าย
  - รหัสผ่านถูกเก็บเป็นข้อความธรรมดาใน config (เหมาะกับระบบขนาดเล็ก) และมีผู้ดูแลระบบบัญชีเดียว

## 6.1 การ Deploy ขึ้นโฮสต์ Windows

```powershell
cd E:\MeterReadingSystem\MeterReadingSystem
dotnet publish -c Release -o E:\publish
```

1. โฮสต์ต้องมี **.NET 10 Hosting Bundle** (IIS) และให้แอปพูลมีสิทธิ์เขียนที่โฟลเดอร์ `App_Data`
2. ฐานข้อมูลคือไฟล์ SQLite `App_Data/meterreading.db` ใน repo นี้มีไฟล์พร้อมข้อมูลตัวอย่างอยู่แล้ว (มิเตอร์ 6 ตัว ค่าอ่าน 79 รายการ) คัดลอกไปวางที่ `App_Data` บนโฮสต์ได้เลย ถ้าไม่มีไฟล์ ระบบจะสร้างฐานข้อมูลว่างให้เองจาก migrations
3. อย่าอัปโหลดทับโฟลเดอร์ `App_Data` บนโฮสต์ตอนอัปเดตโค้ด เพราะข้อมูลจริงอยู่ในนั้น และควรสำรองไฟล์ `.db` ไว้เสมอ
